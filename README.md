# 🪽 SkyShift

> **Flap. Collect. Shift. Conquer.**

**SkyShift** is a fun browser-based flying arcade game inspired by Flappy Bird, with an evolution-based progression system.

Start as a 🐦 bird, survive obstacles, collect special items, unlock unique powers, and evolve into increasingly powerful flying creatures.

## 🧬 Evolution

```text
🐦 Bird → 🦅 Eagle → 🐉 Dragon → 🦄 Flying Horse
```

Each evolution introduces a new environment, collectible, and special ability.

| Stage | World | Collectible | Power |
|---|---|---|---|
| 🐦 Bird | 🌆 City | 🪰 Fly | ⚡ Dash |
| 🦅 Eagle | 🌲 Forest | 🐍 / 🐦 | 👁️ Eagle Vision |
| 🐉 Dragon | 🏔️ Mountains | 🐑 Sheep | 🔥 Fire Breath |
| 🦄 Horse | ☁️ Heaven | ✨ Magic | 🌀 Teleport |

### 🎯 Progression

The planned checkpoints are:

**25 → Eagle → 50 → Dragon → 75 → Flying Horse → 100 → Victory**

Collectibles can be gathered during flight to charge the creature's unique ability.

## 🎮 Controls

- **SPACE / Click / Tap** → Flap
- **E** → Activate Power
- **Mobile** → On-screen power button

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Canvas API

No game engine or framework — just vanilla web technologies.

## 🚧 Status

**Work in Progress**

The basic flying, scoring, obstacles, collision detection, and evolution prototype are currently implemented. More worlds, collectibles, powers, animations, and visual effects are being added progressively.

## 🚀 Run Locally

```bash

```

Open `index.html` in your browser, or use **VS Code + Live Server**.
